# راه‌اندازی بخش «یادآورهای اشتراکی» (فقط با گوشی)

## ۱) ساخت پروژهٔ Supabase
1. در مرورگر گوشی به supabase.com برو و با حساب GitHub یا ایمیل وارد شو.
2. New project → یک نام و یک رمز پایگاه‌داده بده (رمز را نگه دار) → Create. چند دقیقه صبر کن.

## ۲) ساخت جدول‌ها و قوانین امنیتی
1. در منوی پروژه: **SQL Editor** → New query.
2. همهٔ متن فایل `supabase/schema.sql` را بچسبان → **Run**. باید «Success» ببینی.

## ۳) تنظیم ورود
- Authentication → Providers → Email: روشن باشد.
- برای ساده‌تر شدن، «Confirm email» را خاموش کن (وگرنه بعد از ثبت‌نام باید لینک ایمیل را بزنی).

## ۴) گرفتن آدرس و کلید
- Project Settings → API:
  - **Project URL** را کپی کن.
  - کلید **anon public** را کپی کن.
  - ⛔ کلید **service_role** را هرگز در برنامه، گیت‌هاب یا جایی نگذار. برنامه اگر آن را ببیند رد می‌کند.

## ۵) در برنامه
یادآورهای اشتراکی ← آدرس و کلید anon را بچسبان ← ذخیره ← نام + ایمیل + رمز ← ثبت‌نام.
سپس «ساخت گروه»؛ داخل گروه تب «اعضا و دعوت» ← ساخت دعوت ← ارسال متن برای دوستت.
دوستت: یادآورهای اشتراکی ← پیوستن با کد ← چسباندن متن.

## امنیت و محدودیت‌ها (صادقانه)
- یادآورهای شخصی هرگز به سرور نمی‌روند.
- محتوای گروه روی گوشی با AES-256-GCM رمز می‌شود؛ کلید فقط داخل متن دعوت می‌رود، نه به سرور. سرور فقط متن رمزشده، شناسه‌ها و زمان ویرایش را می‌بیند (عنوان‌ها را نه).
- کلید روی گوشی با Android Keystore محافظت می‌شود. ⚠️ متن دعوت شامل کلید است؛ هر کس آن را داشته باشد می‌تواند بپیوندد، پس لغو/انقضا را استفاده کن.
- بیرون‌کردن عضو، دسترسی او به سرور را قطع می‌کند اما کلید را که قبلاً داشته از بین نمی‌برد (چرخش کلید پیاده‌سازی نشده).
- تعارض: آخرین ویرایش (بر اساس ساعت گوشی) برنده است؛ اگر ساعت گوشی‌ها اختلاف زیاد داشته باشد ممکن است ویرایش قدیمی‌تر اشتباهاً برنده شود.
- حذف‌ها به صورت «سنگ‌قبر» همگام می‌شوند.
- یادآورهای اشتراکی فعلاً هشدار/آلارم گوشی ندارند؛ فقط در لیست گروه دیده می‌شوند.
- همگام‌سازی پس‌زمینه با WorkManager تقریباً هر ۱۵ دقیقه است و اندروید ممکن است تأخیر بیندازد؛ لحظه‌ای (Realtime) نیست.
- محدودیت نرخ تلاش برای حدس کد دعوت پیاده‌سازی نشده؛ کد ۱۲ نویسه‌ای و منقضی‌شونده است و بدون کلید محتوا خوانده نمی‌شود.
